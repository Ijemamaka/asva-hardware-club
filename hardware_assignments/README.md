The schematic diagram shows 6 servo motors, a 5v external source, a GND source and an Arduino Uno. 
The positive terminals of the servo motors are connected to the +5v voltage source by connecting them in a bus and connecting the main wire to the 5v source. 
The negative terminals of the servo motors are connected to the GND source by connecting them in a bus and connecting the main wire to the GND source directly. 
The Arduino Uno pins (D2-D7) are connected to the servo's signal pins consecutively, i.e M1 signal pin to D2, M2 signal pin to D3, M3 signal pin to D4, M4 signal pin to D5, M5 signal pin to D6 and M6 signal pin to D7 and the GND pin of the Arduino was connected to the GND source. 
The Servo motors were connected to the 5v power source to provide power to the motors and enable them to move. 
They were also connected to the Arduino Uno because of the code written on them.
